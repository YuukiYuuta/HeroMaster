# Мастер героев — прототип (этап 0)

Текстовый прототип симуляции автономных героев. Цель этапа — проверить, ощущаются ли герои живыми без прямого общения с ними.

## Структура

- `data/heroes.json` — герои, их черты, ценности и стартовые отношения.
- `data/balance.json` — все числа баланса (пороги доверия, скорость обучения и т. д.).
- `data/beliefs.json` — какие выводы герои делают из событий дня (ночная рефлексия).
- `src/HeroMaster.Core` — ядро симуляции (netstandard2.1, C# 9 — совместимо с Unity).
- `src/HeroMaster.Web` — панель мастера в браузере (основной способ играть и проверять).
- `src/HeroMaster.Cli` — консольная оболочка (для быстрых прогонов).
- `tests/HeroMaster.Core.Tests` — автотесты ядра.

## Панель мастера (удобнее всего)

Запуск, затем откройте http://localhost:5080 в браузере:

```bash
dotnet run --project src/HeroMaster.Web
```

Карточки героев, решения мастера галочками и списками, делёж добычи, журнал дня. По клику на имя — всё о герое, включая усвоенные приёмы.

Вверху — «Донесения»: утренняя сводка за прошедший день и отчёт о бое. В карточке героя — «Что думает» (его убеждения, ★ — ключевые воспоминания) и личный дневник.

Если отправить команду на вылазку, день останавливается на живом бое: карта зон, герои и враги, лента событий, пауза и скорость. Кнопка «Сюда!» на зоне — совет всему отряду держать эту позицию; клик по герою — совет только ему. Удачные советы герои медленно запоминают как приёмы.

## ИИ-рассказчик (необязательно)

Без ИИ все тексты (дневники, сводки, отчёты) собираются по шаблонам — игра полностью работает.
Если задать ключ Anthropic API, после каждого дня модель Claude в фоне перепишет эти тексты живее.
Модель только пишет тексты по фактам дня и ничего в игре не решает. Каждый вызов стоит денег; счётчик вызовов и токенов — в строке «ИИ-рассказчик» вверху панели (наведите мышь), он хранится в `saves/ai_usage.json`.

- Ключ: переменная окружения `ANTHROPIC_API_KEY` (задать до запуска панели).
- Настройки — `src/HeroMaster.Web/appsettings.json`, раздел `Narrator`: `Enabled` (вкл/выкл), `Model` (по умолчанию `claude-opus-5-5`), `Effort` (`low` — короткие тексты, дешевле).
- Если модель отказывается писать, сервер сам пробует запасную модель (режим `fallbacks: "default"`).

## Команды

```bash
dotnet test
```

```bash
dotnet run --project src/HeroMaster.Cli -- new 42
```

```bash
dotnet run --project src/HeroMaster.Cli -- play
```

```bash
dotnet run --project src/HeroMaster.Cli -- roster
```

```bash
dotnet run --project src/HeroMaster.Cli -- log
```

`play` — игра день за днём: отправить команду на вылазку (`team`), поделить добычу (`loot` / `keep`), сделать подарок (`gift`), намекнуть герою, чем заняться (`hint`), и прожить день (`go`). Внутри `play` команда `help` показывает примеры.

`new` без числа берёт случайное зерно. Одно и то же зерно всегда даёт одинаковое начало партии.
Сохранение лежит в `saves/world.json`.
